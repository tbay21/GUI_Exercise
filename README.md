# Kasir Mini Market — Java Swing

A simple desktop-based cashier application developed using Java Swing. This project was created as an implementation of Object-Oriented Programming (OOP) concepts, particularly graphical user interface development and event-driven programming.

The application simulates a basic mini-market cashier system, allowing users to select products, manage quantities, process transactions, and calculate payment changes through a graphical interface.

## 1. About the Application

Kasir Mini Market provides a simple interface for handling product transactions. Instead of performing calculations manually, users can interact with buttons and input fields to manage the transaction process.

The application includes the following operations:

- Select a product from the available product list.
- Enter the quantity of the selected product.
- Add products to the transaction.
- Display transaction details in a receipt area.
- Calculate the total purchase amount.
- Enter the customer's payment.
- Calculate and display the change.
- Reset the transaction for a new customer.

## 4. Source Code Implementation

### 4.1 Main Application Class

The main application class extends `JFrame`, which provides the main window, and implements `ActionListener` to handle user interactions.

```java
public class KasirSederhana extends JFrame implements ActionListener {

    public KasirSederhana() {
        setTitle("Kasir Mini Market");
        setSize(600, 500);
        setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
        setLocationRelativeTo(null);
    }

    @Override
    public void actionPerformed(ActionEvent e) {
        
    }
}
```

This structure allows the application to create a graphical window and respond to events generated by interface components.

### 4.2 Organizing the Interface

The interface uses `JPanel` to group related components. Different layout managers are combined to organize the application.

The following example demonstrates the use of `BorderLayout`, `GridLayout`, and `FlowLayout`.

```java
JPanel panelUtama = new JPanel(new BorderLayout());

JPanel panelProduk = new JPanel(new GridLayout(3, 2));
JPanel panelTombol = new JPanel(new FlowLayout());

panelUtama.add(panelProduk, BorderLayout.NORTH);
panelUtama.add(panelTombol, BorderLayout.SOUTH);

add(panelUtama);
```

Each layout manager has a different responsibility:

- `BorderLayout` divides the main container into regions.
- `GridLayout` arranges components in rows and columns.
- `FlowLayout` places components sequentially.

The application uses Swing components to receive input and display transaction information.

These components allow users to interact with the cashier application through product selection, text input, transaction displays, and action buttons.

### 4.4 Event Handling

The application uses the Delegation Event Model. Components generate events, which are handled by registered listeners.

The `ActionListener` interface is implemented by the main class. Components register the class as their listener using `addActionListener()`.

```java
tombolTambah.addActionListener(this);
tombolBayar.addActionListener(this);
tombolReset.addActionListener(this);
comboProduk.addActionListener(this);
```

The `actionPerformed()` method processes the events.

```java
@Override
public void actionPerformed(ActionEvent e) {
    if (e.getSource() == tombolTambah) {
        tambahProduk();
    } else if (e.getSource() == tombolBayar) {
        prosesPembayaran();
    } else if (e.getSource() == tombolReset) {
        resetTransaksi();
    }
}
```

This approach allows multiple components to use the same event-handling method while identifying the source of each event.

### 4.5 Mouse Event Handling

Besides action events, the application also demonstrates mouse event handling through `MouseAdapter`.

```java
areaStruk.addMouseListener(new MouseAdapter() {
    @Override
    public void mouseClicked(MouseEvent e) {
        setTitle("Receipt Selected");
    }
});
```

`MouseAdapter` provides an alternative way to handle mouse events without implementing every method in the `MouseListener` interface.

## 5. Transaction Logic

The cashier application performs basic arithmetic operations to calculate the purchase total and customer's change.

The general calculation is:

\[
\text{Subtotal} = \text{Price} \times \text{Quantity}
\]

\[
\text{Total} = \sum \text{Subtotal}
\]

\[
\text{Change} = \text{Payment} - \text{Total}
\]

For example, if a customer purchases three items priced at Rp10,000 each:

```java
int harga = 10000;
int jumlah = 3;

int subtotal = harga * jumlah;
```

The resulting subtotal is Rp30,000.

The payment process must also verify that the amount entered by the customer is sufficient before calculating the change.

## 7. Running the Project

Make sure Java Development Kit (JDK) is installed on your computer.

**Step 1 — Clone the repository**

```bash
git clone https://github.com/username/KasirMiniMarket.git
```

**Step 2 — Open the project**

Open the project directory using a Java IDE such as NetBeans, IntelliJ IDEA, or Eclipse.

**Step 3 — Compile the source files**

Make sure `KasirSederhana.java` and `Main.java` are in the same directory and package.

**Step 4 — Run the application**

Execute `Main.java` to launch the cashier application.

The main class uses the following code:

```java
public class Main {
    public static void main(String[] args) throws Exception {
        KasirSederhana kasir = new KasirSederhana();
        kasir.setVisible(true);
    }
}
```
